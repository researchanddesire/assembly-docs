# Bill of Materials

## Assembly Components

| Item | Quantity | Notes |
| --- | ---: | --- |
| DTT PCB | 1 | Flash before assembly. |
| DTT loop velcro | 1 | Used on the PCB. |
| 3D printed DTT housing | 1 | Clean interior filament strands before assembly. |
| Screen | 1 | Remove film before installation. |
| Sensor | 1 | Install flush with casing. |
| Battery | 1 | Install writing-side down. |
| Cable harness | 1 | Connects screen, sensor, battery, and PCB. |
| `0408LTFB` screws | 4 | Used to fasten the PCB to the trainer case. |

## Tools

| Tool | Use |
| --- | --- |
| Hot glue gun | Glue screen, sensor, and battery in place. |
| T8 screwdriver bit | Fasten PCB screws. |
| Electric screwdriver or similar | Drive screws. |
| Torch | Gently remove filament strands inside the 3D printed housing. |
