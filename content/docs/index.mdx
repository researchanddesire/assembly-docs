## Contributing

Assembly content is maintained in the public
[researchanddesire/assembly-docs](https://github.com/researchanddesire/assembly-docs)
repository. Open a focused pull request there to correct an instruction, update
an image, or improve a product package.

See [How This Site Works](./how-this-site-works) for the publishing flow and
content boundaries.
