Documentation unifiée de l’assemblage des produits matériels Research and Desire.

Chaque dossier produit regroupe son guide d’assemblage, sa nomenclature, les informations sur les câbles, les références de PCB et
les images d’accompagnement.

## Contributions

Le contenu d’assemblage est maintenu dans le dépôt public
[researchanddesire/assembly-docs](https://github.com/researchanddesire/assembly-docs).
Ouvrez-y une pull request ciblée pour corriger une instruction, mettre à jour une image
ou améliorer un dossier produit.

Consultez [Comment fonctionne ce site](./how-this-site-works) pour connaître le processus de publication et les
limites du contenu.
