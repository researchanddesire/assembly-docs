Le guide d’assemblage OSSM attend sa migration depuis les sources matérielles
opérationnelles actuelles.

## Liste de contrôle de migration

- Confirmez les fichiers CAO de release exportés dans [`hardware/cad/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cad).
- Vérifiez l’état de migration de la source du PCB dans [`hardware/pcb/`](https://github.com/researchanddesire/ossm/tree/main/hardware/pcb).
- Confirmez la sortie du faisceau générée par Wireviz dans [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
- Renseignez [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv) avec les postes au niveau du produit.
- Remplacez cette liste de contrôle par la séquence de construction ordonnée et les photos d’assemblage.

N’inventez pas d’étapes d’assemblage avant que le paquet source de la release ne soit complet.
