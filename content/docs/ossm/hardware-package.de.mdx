Die OSSM-Montagedokumentation wird aus den aktuellen operativen Hardwarequellen in
dieses Repository migriert. Dieses Paket veröffentlicht den assembly-docs-Bereich für Ohai,
während die vollständige Bausequenz und die Release-Assets noch ergänzt
werden.
