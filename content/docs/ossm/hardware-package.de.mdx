Die OSSM-Assembly-Dokumentation wird aus dem in dieses Repository migriert
aktuelle betriebsbereite Hardwarequellen. Dieses Paket veröffentlicht die Assembly-Dokumente
Oberfläche für Ohai, während die komplette Build-Sequenz und die Release-Assets vorliegen
ausgefüllt.
