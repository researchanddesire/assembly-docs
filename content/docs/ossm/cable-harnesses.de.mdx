OSSM-Kabelbaumquellen sind unter [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables) verfügbar.
Wireviz rendert jede Kabelbaumquelle in Diagrammartefakte und ein detailliertes untergeordnetes Element
Stückliste. Die [Stückliste](product-bom.mdx) auf Produktebene sollte jeden Kabelbaum als einen auflisten
Top-Level-Assembly und Link zur Wireviz-Quelle.

## Motorsteuerungskabelbaum

| Vermögenswert             | Standort                                                                                                                               |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Wireviz-Quelle            | [`OSSM-Motor-Control-Harness.yml`](https://github.com/researchanddesire/ossm/blob/main/hardware/cables/OSSM-Motor-Control-Harness.yml) |
| Quellenanmerkungen        | [`hardware/cables/README.md`](https://github.com/researchanddesire/ossm/blob/main/hardware/cables/README.md)                           |
| Generierte Release-Assets | [Neueste OSSM-Version](https://github.com/researchanddesire/ossm/releases/latest)                                                      |

Der Kabelexport-Workflow veröffentlicht generierte Assets von `cable-export/`,
einschließlich:
