# Druckeinstellungen

Verwenden Sie PETG oder ABS, eine Schichthöhe von 0,2–0,28 mm, 4–5 Umfänge und 40–60 % Füllung. Verwenden Sie eine 0,4–0,6-mm-Düse. Richten Sie tragende Teile so aus, dass die Schichtlinien quer zur erwarteten Kraft verlaufen.

# Checkliste für Standardteile

Drucken Sie jeweils eines aus, es sei denn, es wird eine andere Menge angezeigt:

- Körperbasis
- Körpermitte – Standardversion
- Motörhead-Abdeckung
- Gehäuse und Deckel für Leiterplattenmontage
- Riemenklemme: Spannende
- Gürtelklemme: oben
- Gürtelklemme: unten
- PitClamp 57AIM-Ring, unterer Standard, oberer und Griff, Sechskant-Dogbone und runder Dogbone
- Schienen-zu-24-mm-Gewinde-Spielzeughalterung
- 24 mm Kontermutter
- Vac-u-lock-Adapter
- Kabelgebundenes Fernbedienungsgehäuse und obere Abdeckung
- Kabelgebundene Fernbedienungsknöpfe ×2

# Überprüfen Sie jeden Druck

Stützen und loses Material entfernen. Ein Teil mit Rissen, Schichttrennungen, verzerrten Befestigungslöchern oder schlechter Passung auf einer tragenden Oberfläche aussortieren. Bringen Sie das Leiterplattengehäuse trocken an und prüfen Sie, ob die Kontermutter reibungslos auf den 24-mm-Adapter passt.

<Check>
  Fahren Sie nur fort, wenn alle Standardteile vorhanden, sauber und unbeschädigt sind und mit der für diesen Build aufgeführten Hardware übereinstimmen.
</Check>
