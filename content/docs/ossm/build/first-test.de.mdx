# Vor dem Einschalten der Stromversorgung

- Befestigen Sie den Aktuator an seiner Standardhalterung.
- Lassen Sie vor dem Endeffektor mindestens 200 mm freien Spielraum.
- Überprüfen Sie jedes Befestigungselement, jede Riemenausrichtung, jeden Spanner, jeden Stecker und jeden Stromanschluss.
- Hände, Haare, Kleidung, Werkzeuge und Kabel von beweglichen Teilen fernhalten.
- Bringen Sie die Stopp-Steuerung in unmittelbarer Reichweite an.

<Warning>
  Testen Sie keinen ungesicherten Aktuator. Trennen Sie die Stromversorgung sofort, wenn die Bewegung umgekehrt, behindert, instabil oder unerwartet heftig ist.
</Warning>

# Referenzfahrt testen

1. Stellen Sie die Drehzahl des Reglers auf Null.
2. Schließen Sie die offizielle Kabelfernbedienung an oder schalten Sie einen aufgeladenen RADR in der Nähe ein.
3. Schließen Sie die 24-V-Stromversorgung an.
4. Stehen Sie frei und beobachten Sie die vollständige Referenzfahrt.
5. Trennen Sie die Stromversorgung, wenn sich der Schlitten auf ein Hindernis zubewegt, blockiert oder sich in die falsche Richtung bewegt.

# Testen Sie einen kurzen Hub

1. Wählen Sie nach Abschluss der Referenzfahrt den einfachsten Bewegungsmodus aus.
2. Stellen Sie eine kurze Tiefe ein.
3. Erhöhen Sie die Geschwindigkeit nur so weit, dass eine reibungslose Bewegung gewährleistet ist.
4. Halten Sie an und überprüfen Sie, ob die Stoppsteuerung die Bewegung stoppt.
5. Trennen Sie die Stromversorgung und überprüfen Sie den Riemen, die Riemenscheibe, die Befestigungselemente und die Verkabelung noch einmal.

<Check>
  Der OSSM stellt sich in die richtige Richtung ein, bewegt sich reibungslos, ohne dass das Band überspringt oder reibt, und stoppt sofort über die Steuerung.
</Check>

Wenn eine Prüfung fehlschlägt, verwenden Sie [Fehlerbehebung bei der Montage](/ossm/assembly-troubleshooting), bevor Sie die Stromversorgung erneut anlegen.
