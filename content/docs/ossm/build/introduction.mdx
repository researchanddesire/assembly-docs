# Build the official OSSM configuration

This guide covers the standard OSSM actuator, official control board, 100 W integrated servo motor, official printed parts, and wired or RADR controller.

<Warning>
  Assembly includes mains-powered equipment, high-current DC wiring, moving machinery, and pinch points. Disconnect power before wiring or adjusting hardware. If you are not qualified to work safely with the chosen power supply, ask a qualified person to complete that work.
</Warning>

## Build sequence

1. Gather the [tools and parts](/ossm/build/tools-and-parts).
2. Check the [bill of materials](/ossm/build/bill-of-materials) and [printed parts](/ossm/build/printed-parts).
3. Assemble the rail, belt, tensioners, and end effector.
4. Assemble the motorhead and set belt tension.
5. Mount the electronics and complete the wiring.
6. Secure the actuator, clear the motion path, and perform the first test at low speed.

## Before continuing

- Read each stage before starting it.
- Match every fastener to the parts table for that stage.
- Do not substitute electrical components without reviewing the supported specifications.
- Keep power disconnected until the first-test page explicitly tells you to connect it.

<Check>
  Continue only when you have a clear work area, the correct official parts, and a safe way to disconnect power immediately.
</Check>
