## Bauen Sie die offizielle OSSM-Konfiguration

Dieser Leitfaden behandelt den Standard-OSSM-Aktuator, die offizielle Steuerplatine, den integrierten 100-W-Servomotor, die offiziellen Druckteile sowie einen kabelgebundenen Controller oder RADR.

<Warning>
  Die Montage umfasst netzbetriebene Geräte, Gleichstromverkabelung für hohe Ströme, bewegliche Maschinen und Quetschstellen. Trennen Sie die Stromversorgung, bevor Sie die Verkabelung anschließen oder Hardware anpassen. Wenn Sie nicht qualifiziert sind, sicher mit der gewählten Stromversorgung zu arbeiten, beauftragen Sie eine qualifizierte Person mit dieser Arbeit.
</Warning>

## Bauabfolge

1. Sammeln Sie die [Werkzeuge und Teile](/ossm/build/tools-and-parts).
2. Überprüfen Sie die [Stückliste](/ossm/build/bill-of-materials) und die [gedruckten Teile](/ossm/build/printed-parts).
3. Montieren Sie die Schiene, den Riemen, die Spannelemente und den Endeffektor.
4. Montieren Sie den Motorkopf und stellen Sie die Riemenspannung ein.
5. Montieren Sie die Elektronik und schließen Sie die Verkabelung ab.
6. Sichern Sie den Aktuator, räumen Sie den Bewegungsweg frei und führen Sie den ersten Test bei niedriger Geschwindigkeit durch.

## Bevor Sie fortfahren

- Lesen Sie jede Phase, bevor Sie damit beginnen.
- Gleichen Sie jedes Befestigungselement mit der Teiletabelle für diese Phase ab.
- Tauschen Sie elektrische Komponenten nicht aus, ohne die freigegebenen Spezifikationen zu prüfen.
- Lassen Sie die Stromversorgung getrennt, bis auf der Seite zum ersten Test ausdrücklich dazu aufgefordert wird, sie anzuschließen.

<Check>
  Fahren Sie nur fort, wenn Sie über einen freien Arbeitsbereich, die richtigen offiziellen Teile und eine sichere Möglichkeit verfügen, die Stromversorgung sofort zu trennen.
</Check>
