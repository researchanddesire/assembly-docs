# Erstellen Sie die offizielle OSSM-Konfiguration

Dieses Handbuch behandelt den Standard-OSSM-Antrieb, die offizielle Steuerplatine, den integrierten 100-W-Servomotor, offizielle gedruckte Teile und den kabelgebundenen oder RADR-Controller.

<Warning>
  Die Montage umfasst netzbetriebene Geräte, Hochstrom-Gleichstromkabel, bewegliche Maschinen und Quetschstellen. Trennen Sie die Stromversorgung, bevor Sie die Hardware verkabeln oder anpassen. Wenn Sie nicht über die nötige Qualifikation für die sichere Arbeit mit der gewählten Stromversorgung verfügen, beauftragen Sie eine qualifizierte Person mit der Durchführung dieser Arbeiten.
</Warning>

## Build-Sequenz

1. Sammeln Sie die [Werkzeuge und Teile](/ossm/build/tools-and-parts).
2. Überprüfen Sie die [Stückliste](/ossm/build/bill-of-materials) und die [gedruckten Teile](/ossm/build/printed-parts).
3. Montieren Sie Schiene, Riemen, Spanner und Endeffektor.
4. Montieren Sie den Motorkopf und stellen Sie die Riemenspannung ein.
5. Montieren Sie die Elektronik und schließen Sie die Verkabelung ab.
6. Sichern Sie den Aktuator, geben Sie den Bewegungspfad frei und führen Sie den ersten Test bei niedriger Geschwindigkeit durch.

## Bevor Sie fortfahren

- Lesen Sie jede Phase, bevor Sie damit beginnen.
- Ordnen Sie jedes Befestigungselement der Teiletabelle für diese Phase zu.
- Tauschen Sie elektrische Komponenten nicht aus, ohne die unterstützten Spezifikationen zu überprüfen.
- Lassen Sie die Stromversorgung unterbrochen, bis Sie auf der Seite des ersten Tests ausdrücklich dazu aufgefordert werden, das Gerät anzuschließen.

<Check>
  Fahren Sie nur fort, wenn Sie über einen freien Arbeitsbereich, die richtigen offiziellen Teile und eine sichere Möglichkeit verfügen, die Stromversorgung sofort zu trennen.
</Check>
