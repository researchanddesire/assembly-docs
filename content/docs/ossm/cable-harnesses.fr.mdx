Les sources des faisceaux de câbles OSSM se trouvent dans [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
Wireviz génère pour chaque source de faisceau des diagrammes et une nomenclature détaillée
des sous-composants. La [nomenclature](product-bom) au niveau du produit doit répertorier chaque faisceau comme un assemblage de niveau supérieur
et contenir un lien vers la source Wireviz.

## Faisceau de commande du moteur

| Ressource                 | Emplacement                                                                                                                            |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Source Wireviz            | [`OSSM-Motor-Control-Harness.yml`](https://github.com/researchanddesire/ossm/blob/main/hardware/cables/OSSM-Motor-Control-Harness.yml) |
| Notes sur la source       | [`hardware/cables/README.md`](https://github.com/researchanddesire/ossm/blob/main/hardware/cables/README.md)                           |
| Fichiers de version générés | [Dernière version d’OSSM](https://github.com/researchanddesire/ossm/releases/latest)                                                 |

Le workflow d’export des câbles publie les fichiers générés à partir de `cable-export/`,
notamment :

- `OSSM-Motor-Control-Harness.pdf`
- `OSSM-Motor-Control-Harness.png`
- `OSSM-Motor-Control-Harness.bom.tsv`
