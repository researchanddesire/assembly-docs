OSSM-assemblagedocumentatie wordt naar deze repository gemigreerd vanuit de
huidige operationele hardwarebronnen. Dit pakket publiceert de assembly-docs
oppervlak voor Ohai terwijl de volledige bouwvolgorde en release-items plaatsvinden
ingevuld.

## Bronkaart

| Gebied                              | Bron                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------ |
| Stuklijst op productniveau          | [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv) |
| Export van CAD-releases             | [`hardware/cad/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cad)        |
| PCB-bronnotities                    | [`hardware/pcb/`](https://github.com/researchanddesire/ossm/tree/main/hardware/pcb)        |
| Kabelboombronnen                    | [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables)  |
| Huidige upstream-hardwarereferentie | [KinkyMakers/OSSM-hardware](https://github.com/KinkyMakers/OSSM-hardware)                  |
