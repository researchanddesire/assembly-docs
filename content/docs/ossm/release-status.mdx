## Migration Checklist

- Confirm the release CAD exports in [`hardware/cad/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cad).
- Confirm PCB source migration status in [`hardware/pcb/`](https://github.com/researchanddesire/ossm/tree/main/hardware/pcb).
- Confirm Wireviz harness output from [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
- Populate [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv) with product-level line items.
- Replace this checklist with the ordered build sequence and assembly photos.

Do not invent assembly steps before the release source package is complete.
