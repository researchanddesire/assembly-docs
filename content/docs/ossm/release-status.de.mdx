Die OSSM-Montageanleitung wartet auf die Migration aus den aktuellen operativen
Hardwarequellen.

## Migrationscheckliste

- Bestätigen Sie die CAD-Release-Exporte in [`hardware/cad/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cad).
- Bestätigen Sie den Migrationsstatus der PCB-Quelle in [`hardware/pcb/`](https://github.com/researchanddesire/ossm/tree/main/hardware/pcb).
- Bestätigen Sie die Wireviz-Kabelbaumausgabe aus [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
- Füllen Sie [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv) mit Positionen auf Produktebene.
- Ersetzen Sie diese Checkliste durch die geordnete Bauabfolge und Montagefotos.

Erfinden Sie keine Montageschritte, bevor das Release-Quellpaket vollständig ist.
