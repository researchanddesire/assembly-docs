Der OSSM-Montageleitfaden wartet auf die Migration vom aktuellen Betrieb
Hardwarequellen.

## Migrationscheckliste

- Bestätigen Sie die freigegebenen CAD-Exporte in [`hardware/cad/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cad).
- Bestätigen Sie den Migrationsstatus der PCB-Quelle in [`hardware/pcb/`](https://github.com/researchanddesire/ossm/tree/main/hardware/pcb).
- Bestätigen Sie die Ausgabe des Wireviz-Kabelbaums von [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
- Füllen Sie [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv) mit Werbebuchungen auf Produktebene.
- Ersetzen Sie diese Checkliste durch die geordnete Baureihenfolge und Montagefotos.

Erfinden Sie keine Montageschritte, bevor das Release-Quellpaket vollständig ist.
