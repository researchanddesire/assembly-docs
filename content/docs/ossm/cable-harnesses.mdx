OSSM cable harness sources live under [`hardware/cables/`](https://github.com/researchanddesire/ossm/tree/main/hardware/cables).
Wireviz renders each harness source into diagram artifacts and a detailed child
BOM. The product-level [Bill of Materials](product-bom) should list each harness as a
top-level assembly and link to the Wireviz source.
