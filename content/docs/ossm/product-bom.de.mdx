Die OSSM-Stückliste auf Produktebene wird aus [`hardware/bom.csv`](https://github.com/researchanddesire/ossm/blob/main/hardware/bom.csv)
während des Builds von assembly-docs generiert. Aktualisieren Sie die CSV-Datei,
anstatt den generierten Block von Hand zu bearbeiten.

Die Stückliste dient derzeit als Platzhalter für die Migration und enthält nur eine Kopfzeile. Bis Produktzeilen
hinzugefügt werden, lässt Ohai den Text dieser Seite unverändert.
