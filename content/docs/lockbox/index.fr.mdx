## But

Cette documentation rassemble les informations d’assemblage du matériel Lockbox pour les constructeurs OSS
et les partenaires de fabrication.

## Présentation de Lockbox

Lockbox est un produit électronique grand public de petite taille, construit autour d’un PCB personnalisé, du micrologiciel ESP32-S3, d’un loquet motorisé, de capteurs magnétiques, d’un écran TFT, d’un encodeur rotatif, d’une batterie et d’un boîtier en plastique imprimé en 3D.

![Présentation du dispositif Lockbox](assets/device-overview.webp)

| Propriété                  | Valeur                                        |
| -------------------------- | --------------------------------------------- |
| Dimensions                 | 57 mm x 43 mm x 134 mm                        |
| Volume de plastique        | 156,408.422 mm^3                              |
| Matériau actuel du boîtier | Plastique PLA imprimé en 3D                   |
| Aimants intégrés           | Trois à quatre aimants dans le boîtier en plastique |
