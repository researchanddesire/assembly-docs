## Zweck

Diese Dokumente sammeln die Informationen zur Lockbox-Hardware-Assembly in einem eigenständigen Ordner für die zukünftige Aggregation in `ohai.researchanddesire.com`. Sie sind als offene Hardware-Montageanleitungen für OSS-Erbauer und Fertigungsmitarbeiter verfasst.

## Lockboxübersicht

Lockbox ist ein kleines Unterhaltungselektronikprodukt, das auf einer benutzerdefinierten Leiterplatte, der ESP32-S3-Firmware, einem motorisierten Riegel, magnetischen Sensoren, einem TFT-Display, einem Drehgeber, einer Batterie und einem 3D-gedruckten Kunststoffgehäuse basiert.

![Übersicht über Lockbox-Geräte](assets/device-overview.webp)

| Eigentum                  | Wert                                       |
| ------------------------- | ------------------------------------------ |
| Abmessungen               | 57 mm x 43 mm x 134 mm                     |
| Plastikvolumen            | 156.408,422 mm^3                           |
| Aktuelles Gehäusematerial | 3D-gedruckter PLA-Kunststoff               |
| Eingebettete Magnete      | Drei bis vier Magnete im Kunststoffgehäuse |
