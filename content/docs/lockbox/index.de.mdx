## Zweck

Diese Dokumentation bündelt die Informationen zur Montage der Lockbox-Hardware für OSS-Erbauer
und Fertigungspartner.

## Lockbox-Übersicht

Lockbox ist ein kompaktes Produkt der Unterhaltungselektronik auf Basis einer kundenspezifischen Leiterplatte, der ESP32-S3-Firmware, eines motorisierten Riegels, magnetischer Sensoren, eines TFT-Displays, eines Drehgebers, einer Batterie und eines 3D-gedruckten Kunststoffgehäuses.

![Übersicht über das Lockbox-Gerät](assets/device-overview.webp)

| Eigenschaft               | Wert                                         |
| ------------------------ | -------------------------------------------- |
| Abmessungen              | 57 mm x 43 mm x 134 mm                       |
| Kunststoffvolumen        | 156,408.422 mm^3                             |
| Aktuelles Gehäusematerial | 3D-gedruckter PLA-Kunststoff                |
| Eingebettete Magnete     | Drei bis vier Magnete im Kunststoffgehäuse  |
