Die Lockbox-Platine ist die Steuer- und Stromverteilungsplatine für das Gerät. Es verfügt über die ESP32-S3-Steuerelektronik, eine Motortreiberschnittstelle, einen Batterie- und USB-Strompfad, eine magnetische Positionserkennung, Drehgebereingänge, Tasteneingänge und einen TFT-Display-Anschluss.

<Card title="KiCad-Board-Datei" href="./assets/kicanvas/LockBox.kicad_pcb">
  Laden Sie die Board-Datei für KiCanvas oder KiCad herunter.
</Card>

## Elektrische Architektur

| Bereich                       | Rolle                                                                                             |
| ----------------------------- | ------------------------------------------------------------------------------------------------- |
| `battery_and_power.kicad_sch` | Batterieeingang, USB-Stromerkennung, Lade-/Stromregelung und Unterstützung der Strommessung       |
| `mcu_and_ui.kicad_sch`        | ESP32-S3, Drehgeber, Tasteneingänge, Display-Schnittstelle und benutzerorientierte Bedienelemente |
| `mag_sensors.kicad_sch`       | Hall/TMR-Magnetsensor zur Erkennung der Rückplatten- und Verriegelungsposition                    |
| `motor.kicad_sch`             | DC-Motorausgang und Motorstecker                                                                  |
| `screen.kicad_sch`            | TFT-Display-Anschluss und unterstützende Anzeigesignale                                           |
