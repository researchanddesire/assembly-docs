## Lockbox-overzicht

Lockbox is een kleinschalig consumentenelektronicaproduct dat is opgebouwd rond een aangepaste PCB, ESP32-S3-firmware, een gemotoriseerde vergrendeling, magnetische sensoren, TFT-display, roterende encoder, batterij en 3D-geprinte plastic behuizing.

![Overzicht lockbox-apparaten](assets/device-overview.webp)

| Eigendom                       | Waarde                                           |
| ------------------------------ | ------------------------------------------------ |
| Afmetingen                     | 57 mm x 43 mm x 134 mm                           |
| Kunststof volume               | 156.408,422 mm^3                                 |
| Huidig ​​huisvestingsmateriaal | 3D-geprint PLA-plastic                           |
| Ingebouwde magneten            | Drie tot vier magneten in de kunststof behuizing |
