## Doel

Deze documentatie verzamelt de informatie over de assemblage van Lockbox-hardware voor OSS-bouwers
en productiepartners.

## Lockbox-overzicht

Lockbox is een compact consumentenelektronicaproduct dat is opgebouwd rond een aangepaste PCB, ESP32-S3-firmware, een gemotoriseerde vergrendeling, magnetische sensoren, een TFT-display, een roterende encoder, een batterij en een 3D-geprinte kunststof behuizing.

![Overzicht van het Lockbox-apparaat](assets/device-overview.webp)

| Eigenschap                    | Waarde                                         |
| ----------------------------- | ---------------------------------------------- |
| Afmetingen                    | 57 mm x 43 mm x 134 mm                         |
| Kunststofvolume               | 156,408.422 mm^3                               |
| Huidig behuizingsmateriaal    | 3D-geprinte PLA-kunststof                      |
| Ingebouwde magneten           | Drie tot vier magneten in de kunststof behuizing |
