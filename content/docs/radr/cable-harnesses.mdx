RADR does not currently publish a Wireviz harness source under
`hardware/cables/`. The product-level [Bill of Materials](bill-of-materials) tracks
cable-related items, including the USB-A to USB-C power cable, as top-level
line items.

When a RADR harness source is added, place the Wireviz YAML in
`hardware/cables/` and link the generated diagram and child BOM artifacts from
this page.

| Asset               | Location                                                                                       | Notes                                   |
| ------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------- |
| Cable source folder | [`hardware/cables/`](https://github.com/researchanddesire/RADR-OSS/tree/main/hardware/cables)  | Wireviz YAML sources belong here.       |
| Product-level BOM   | [`hardware/bom.csv`](https://github.com/researchanddesire/RADR-OSS/blob/main/hardware/bom.csv) | Lists cable items at the product level. |
