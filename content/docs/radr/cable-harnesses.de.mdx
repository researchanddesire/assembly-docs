{/* Ported from MkDocs: cable-harnesses.md */}

RADR veröffentlicht derzeit keine Wireviz-Kabelbaumquelle unter
`hardware/cables/`. Die [Stückliste](bill-of-materials.mdx) auf Produktebene verfolgt
Kabelbezogene Artikel, einschließlich des USB-A-zu-USB-C-Stromkabels, als Top-Level
Werbebuchungen.

Wenn eine RADR-Kabelbaumquelle hinzugefügt wird, platzieren Sie die Wireviz-YAML darin
`hardware/cables/` und verknüpfen Sie das generierte Diagramm und die untergeordneten Stücklistenartefakte von
diese Seite.

| Vermögenswert               | Standort                                                                                       | Notizen                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------- |
| Kabelquellenordner          | [`hardware/cables/`](https://github.com/researchanddesire/RADR-OSS/tree/main/hardware/cables)  | Wireviz YAML-Quellen gehören hierher.     |
| Stückliste auf Produktebene | [`hardware/bom.csv`](https://github.com/researchanddesire/RADR-OSS/blob/main/hardware/bom.csv) | Listet Kabelartikel auf Produktebene auf. |
