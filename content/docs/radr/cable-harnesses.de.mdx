{/* Ported from MkDocs: cable-harnesses.md */}

RADR veröffentlicht derzeit keine Wireviz-Quelle für Kabelbäume unter
`hardware/cables/`. Die [Stückliste](bill-of-materials) auf Produktebene erfasst
kabelbezogene Artikel, darunter das USB-A-zu-USB-C-Stromkabel, als Positionen
auf oberster Ebene.

Wenn eine RADR-Kabelbaumquelle hinzugefügt wird, platzieren Sie die Wireviz-YAML-Datei in
`hardware/cables/` und verknüpfen Sie das generierte Diagramm sowie die Artefakte der
untergeordneten Stückliste auf dieser Seite.

| Ressource                   | Speicherort                                                                                    | Hinweise                                  |
| --------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------- |
| Quellordner für Kabelbäume | [`hardware/cables/`](https://github.com/researchanddesire/RADR-OSS/tree/main/hardware/cables)  | Die Wireviz-YAML-Quellen gehören hierher. |
| Stückliste auf Produktebene | [`hardware/bom.csv`](https://github.com/researchanddesire/RADR-OSS/blob/main/hardware/bom.csv) | Erfasst Kabelartikel auf Produktebene.    |
