Die drahtlose RADR-Fernbedienung verwendet eine individuell bestückte Leiterplattenbaugruppe, ein Display, eine Batterie, 3D-gedruckte Gehäuseteile, gedruckte Bedienelemente, Dichtungsstreifen und dreiflügelige Schrauben.

## Teile

Diese Teileliste wird während der Erstellung der Baugruppendokumente aus [`hardware/bom.csv`](https://github.com/researchanddesire/RADR-OSS/blob/main/hardware/bom.csv) generiert. Bearbeiten Sie die generierte Tabelle nicht manuell. Aktualisieren Sie stattdessen die CSV-Datei. Auf die Teile wird in der gesamten [Montageanleitung](assembly-guide.mdx) verwiesen.

## Montagewerkzeuge und Werkstattbedarf

| Artikel                             | Verwenden Sie                                                              |
| ----------------------------------- | -------------------------------------------------------------------------- |
| Raspel                              | Entgraten der PCBA-Kante vor der Montage des Gehäuses.                     |
| T8-Schraubendreherbit               | Anbringen der Schrauben des Tri-Lobe-Gehäuses.                             |
| Elektroschrauber oder Handschrauber | Schrauben für Antriebsgehäuse und Batterieabdeckung.                       |
| Isopropylalkohol                    | Reinigen Sie die PCBA vor der Installation des Dichtungsstreifens.         |
| Mikrofasertuch                      | Reinigung der PCBA und Schutz kosmetischer Oberflächen.                    |
| Rasierklinge                        | Trimmen der Merkmale des vorderen Stoßstangengehäuses.                     |
| Heißklebepistole                    | Befestigen des Displays im vorderen Gehäuse.                               |
| Kleiner Schraubenzieher             | Öffnen Sie den Display-Flachbandstecker und reinigen Sie die Knopfbohrung. |
