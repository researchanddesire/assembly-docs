Die drahtlose RADR-Fernbedienung verwendet eine individuell bestückte Leiterplattenbaugruppe, ein Display, eine Batterie, 3D-gedruckte Gehäuseteile, gedruckte Bedienelemente, Dichtungsstreifen und tri-lobe-Schrauben.

## Teile

Diese Teileliste wird während der Erstellung der Baugruppendokumente aus [`hardware/bom.csv`](https://github.com/researchanddesire/RADR-OSS/blob/main/hardware/bom.csv) generiert. Bearbeiten Sie die generierte Tabelle nicht manuell. Aktualisieren Sie stattdessen die CSV-Datei. Auf die Teile wird in der gesamten [Montageanleitung](assembly-guide) verwiesen.

## Montagewerkzeuge und Werkstattbedarf

| Artikel                             | Verwendung                                                              |
| ----------------------------------- | -------------------------------------------------------------------------- |
| Raspel                              | Entgraten der PCBA-Kante vor der Montage des Gehäuses.                     |
| T8-Schraubendreherbit               | Anbringen der tri-lobe-Gehäuseschrauben.                                 |
| Elektroschrauber oder Handschrauber | Eindrehen der Schrauben für Gehäuse und Batterieabdeckung.                       |
| Isopropylalkohol                    | Reinigen der PCBA vor der Installation des Dichtungsstreifens.         |
| Mikrofasertuch                      | Reinigung der PCBA und Schutz kosmetischer Oberflächen.                    |
| Rasierklinge                        | Trimmen der Pufferelemente des Vordergehäuses.                     |
| Heißklebepistole                    | Befestigen des Displays im vorderen Gehäuse.                               |
| Kleiner Schraubendreher             | Öffnen des Display-Flachbandsteckers und Reinigen der Knopfbohrung. |
