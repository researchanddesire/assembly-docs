## Product Overview

This build uses a DTT PCB, loop velcro, 3D printed DTT housing, screen, sensor, battery, cable harness, and four `0408LTFB` screws.

## Materials and Part Notes

- Housing: 3D printed DTT housing.
- PCB attachment: DTT loop velcro.
