Der DT-Trainer-Aufbau verwendet eine bestückte Leiterplattenbaugruppe mit externem Display, Sensor, Batterie, Kabelbaum, Klettverschluss, 3D-gedrucktem Gehäuse, Schrauben und Montagekleber, die für den All-in-One-Gehäuseaufbau erforderlich sind.

## Teile

Diese Tabelle wird während des Assembly-Docs-Builds aus [hardware/bom.csv](https://github.com/researchanddesire/DT_Trainer-OSS/blob/main/hardware/bom.csv) generiert. Aktualisieren Sie die CSV-Datei, anstatt die generierte Tabelle manuell zu bearbeiten.

## Montagewerkzeuge

| Werkzeug              | Verwenden Sie                                                                   |
| --------------------- | ------------------------------------------------------------------------------- |
| Heißklebepistole      | Kleben Sie Bildschirm, Sensor und Batterie fest.                                |
| T8-Schraubendreherbit | Platinenschrauben festziehen.                                                   |
| Elektroschrauber o.ä. | Antriebsschrauben.                                                              |
| Taschenlampe          | Entfernen Sie vorsichtig Filamentstränge im Inneren des 3D-gedruckten Gehäuses. |
