## Purpose

Assemble the Deepthroat Trainer 2026 updated all-in-one case build from the prepared PCB, housing, screen, sensor, battery, cable harness, velcro, and screws.

## Required Parts and Consumables

- DTT PCB
- DTT loop velcro
- 3D printed DTT housing
- Screen
- Sensor
- Battery
- Cable harness
- 4x `0408LTFB` screws
- Hot glue

## Tools

- Hot glue gun
- T8 screwdriver bit
- Electric screwdriver or similar
- Torch

## Assembly Steps

1. Install the screen.

    Remove the film from the screen. Bend the ribbon gently inwards. Align the screen with the registration features and glue it into place with hot glue. Ensure the hot glue does not block the button arm.

    <figure className="photo-frame" style={{ maxWidth: "420px", margin: "0.75rem 0 1.5rem 1.5rem" }}>
      <img src="assets/display-installed-in-case.png" alt="Screen installed in the trainer case" style={{ width: "100%", height: "auto" }} />
      <figcaption>Screen installed in the case.</figcaption>
    </figure>

2. Install the sensor.

    Use a screwdriver to gently insert the sensor into the casing, pressing on the silver screws to add force without breaking the plastic. Make sure the sensor lays flush with the casing. Glue it into place with hot glue.

3. Install the battery.

    Insert the battery writing-side down. Run a bead of glue along the top bar to secure it in place.

4. Connect the screen and sensor harness.

5. Connect the harness to the PCB.

    Clip the harness into the PCB using the appropriate connectors.

6. Route the wires.

    Route the wires around the peg as shown, and push the wires deeper into the housing, avoiding the button and other pinch points.

7. Fasten the PCB to the trainer case.

    Use the screwdriver to fasten the PCB to the trainer case.

## Final Assembly

1. Confirm the screen is glued in place and the button arm is not blocked.
2. Confirm the sensor is flush with the casing and glued in place.
3. Confirm the battery is secured writing-side down.
4. Confirm the harness is connected to the screen, sensor, and PCB.
5. Confirm wires are routed around the peg and pushed away from the button and pinch points.
6. Confirm the PCB is fastened to the trainer case with the four `0408LTFB` screws.

## QC Checklist

- [ ] PCB was flashed before assembly.
- [ ] Interior filament strands were removed from the 3D printed housing.
- [ ] Screen film was removed.
- [ ] Screen ribbon was bent gently inward.
- [ ] Screen was aligned with registration features.
- [ ] Hot glue does not block the button arm.
- [ ] Sensor lays flush with the casing.
- [ ] Sensor is glued in place.
- [ ] Battery is installed writing-side down.
- [ ] Battery is secured with glue along the top bar.
- [ ] Black harness connector is seated over the screen pins.
- [ ] White connector is clipped into the sensor.
- [ ] Harness is clipped into the PCB connectors.
- [ ] Wires are routed around the peg.
- [ ] Wires are pushed deeper into the housing and avoid the button and pinch points.
- [ ] PCB is fastened to the trainer case.
