Der Aufbau von DT Trainer umfasst einen Kabelbaum für den Bildschirm, den Sensor, die Batterie und das PCB
als Baugruppenposition der obersten Ebene in der [Stückliste](bill-of-materials).

Noch keine Wireviz-Kabelbaumquelle wurde nach `hardware/cables/` migriert. Wenn eine
Wireviz-Quelle hinzugefügt wird, konzentrieren Sie die Stückliste auf Produktebene weiterhin auf die
Kabelbaum-Baugruppe und verknüpfen Sie von dieser Seite aus die detaillierte Ausgabe der untergeordneten Stückliste.

| Element                     | Speicherort                                                                                          | Hinweise                                           |
| --------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Kabelquellenordner          | [`hardware/cables/`](https://github.com/researchanddesire/DT_Trainer-OSS/tree/main/hardware/cables)  | Wireviz YAML-Quellen gehören hierher.              |
| Stückliste auf Produktebene | [`hardware/bom.csv`](https://github.com/researchanddesire/DT_Trainer-OSS/blob/main/hardware/bom.csv) | Listet den Kabelbaum als Baugruppenposition auf.   |
