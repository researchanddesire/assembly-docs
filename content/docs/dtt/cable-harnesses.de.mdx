Der DT-Trainer-Aufbau umfasst einen Bildschirm, einen Sensor, eine Batterie und einen PCB-Kabelbaum
als Baugruppenartikel der obersten Ebene in der [Stückliste](bill-of-materials.mdx).

Es wurde noch keine Wireviz-Kabelbaumquelle auf `hardware/cables/` migriert. Wenn ein
Wenn die Wireviz-Quelle hinzugefügt wird, konzentrieren Sie sich bei der Stückliste auf Produktebene auf den Kabelbaum
Baugruppe und verknüpfen Sie die detaillierte untergeordnete Stücklistenausgabe von dieser Seite.

| Vermögenswert               | Standort                                                                                             | Notizen                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Kabelquellenordner          | [`hardware/cables/`](https://github.com/researchanddesire/DT_Trainer-OSS/tree/main/hardware/cables)  | Wireviz YAML-Quellen gehören hierher.              |
| Stückliste auf Produktebene | [`hardware/bom.csv`](https://github.com/researchanddesire/DT_Trainer-OSS/blob/main/hardware/bom.csv) | Listet den Kabelbaum als Montagelinienartikel auf. |
